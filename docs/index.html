The useful middle layer

the way terminals work.

01

Repositories, not projects

Roadie finds your local GitHub-shaped repos and puts their roadmap issues in one calm overview. Open a board only when you need the detail.

local scan → remote detail
02

Five honest states

idea to planned to now to working to done. No phantom project metadata, just labels and closed issues.

03

Keep your attention

One active item per repo. The WIP limit is visible in the board, so “working” stays a decision rather than a parking lot.

01 WIP / repo
04

Cache first, fetch behind

Cards appear from disk immediately. Missing stats load asynchronously, and your own actions update the cache so it never falls behind.

05

GitHub stays the source of truth

Roadie uses GitHub Issues, not Projects v2. Create, move, comment, close, and reopen from the TUI while the familiar issue history remains in GitHub.

issue-only / no lock-in
